# CHAPTER 05 · 마지막 추리

「꾸한성: 안개 속 별장」 마지막 챕터. 기존 CH1–CH4의 게임 데이터와 캐릭터·배경을 재사용합니다.

## 플레이

1. 챕터 4의 퍼즐 P07–P11과 조사를 완료하면 챕터 5 버튼이 열립니다.
2. 6개 실제 사건 시각을 직접 조립하고 독립 기록과 대조합니다.
3. 범인, 범행 시간대, 만남 장소, 수법, 동선, CCTV 알리바이, 동기, 증거 3축의 **8칸 재구성**을 수행합니다.
4. CCTV, 서재 접근 경로, 8년 전 서명 관련 **3개 반박에 각각 증거**를 제시합니다.
5. 결과에 따라 TRUE / NORMAL / BAD END로 분기합니다. BAD 이후 결론을 수정할 수 있습니다.

## 개발 원칙

- 어떤 인물의 거짓말도 단독으로 범죄를 입증하지 않습니다.
- 스마트워치만으로 초 단위 사망 시각을 단정하지 않습니다.
- CCTV 표시 시각과 실제 시각을 구별합니다.
- 꾸한성 멤버 10명의 범죄 행위는 설정하지 않았으며, 모든 내용은 팬게임용 허구입니다.
- API 호출이나 AI 비용 발생 없음. 이 버전은 정적 게임이며 실제 자유질문 AI 기능은 포함되지 않습니다.
- 로컬 저장키: `gguhansung-fog-villa-ch5-v1`.
- **스포일러 주의:** 정적 JS 파일을 볼 수 있는 사람에게 최종 정답은 숨길 수 없습니다. 서버에서 판정하도록 설계를 변경하기 전까지는 소스 분석 방지 불가.
