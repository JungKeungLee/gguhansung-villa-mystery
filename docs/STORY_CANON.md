# 공식 스토리 설정 (STORY CANON)

> 스포일러를 포함합니다. 이 문서가 **스토리 판단의 기준**입니다. 근거와 상세 분석은 `docs/STORY_AUDIT.md`에 있고, 이미지 제작 기준은 `docs/EVIDENCE_IMAGE_SPEC.md`에 있습니다.

**상태 표기**
- **확정** = 게임 코드에 명시된 사실 (파일과 ID를 근거로 표기)
- **추정** = 코드에서 논리적으로 도출되지만 명시되지는 않음
- **결정 필요** = 코드에 없음. 이미지에만 있거나 정보가 없음. 아래 **D 목록**에서 결정합니다.
- **사용자 확정** = 코드에는 없지만 사용자가 결정한 공식 설정 (E-1장, 결정일 2026-11-12). 코드 사실(확정)과 구별해 표기합니다.

**규칙**
- 결정 필요 항목은 결정되기 전까지 이미지나 텍스트에 **확정된 사실처럼 넣지 않습니다.**
- 이미지에만 있는 값(연도, 등록번호, 지명)은 코드 설정이 아닙니다.
