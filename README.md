# 꾸한성: 안개 속 별장

시청자가 탐정이 되어 꾸한성 멤버 10명과 함께 산속 별장에서 일어난 수상한 사건을 조사하는 스토리형 팬게임입니다.

## 현재 구현 범위

- **CHAPTER 01: 웃음이 가득한 별장** (플레이 가능)
- 탐정 닉네임 입력 · 멤버들과 대화 · 거실/현관/주방/테라스 탐색
- 단서 7개, 탐정 수첩, 힌트, 자동 저장 및 이어하기
- PC와 모바일 화면 지원
- 챕터 2~5는 개발 예정

## 로컬 실행

정적 HTML/CSS/JavaScript로 작성되어 패키지 설치가 필요 없습니다.

1. `index.html`을 Chrome/Edge로 열어 플레이
2. 또는 `python -m http.server 8000` 실행 후 http://localhost:8000 접속

## Vercel 배포

1. Vercel에서 **Add New → Project** 선택
2. GitHub 저장소 `JungKeungLee/gguhansung-villa-mystery` Import
3. Framework Preset: **Other**
4. Root Directory: `./`, Build Command: **없음**, Output Directory: **./** (필요 시 지정)
5. Deploy 선택

이후 `main` 브랜치에 커밋하면 별도 Vercel 프로젝트로 자동 배포됩니다.

## 안내

꾸한성 멤버들의 역할과 대사는 팬게임을 위한 창작이며, 실제 인물의 행위나 성격을 주장하지 않습니다. 프로젝트는 기존 카드게임 코드와 독립적으로 관리합니다.
